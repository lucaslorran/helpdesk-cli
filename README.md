# HelpDesk CLI

Sistema de gerenciamento de chamados de suporte técnico desenvolvido em Java.

O projeto tem como objetivo colocar em prática os fundamentos da linguagem Java e conceitos de Programação Orientada a Objetos por meio de uma aplicação de linha de comando.

> **Status:** Em desenvolvimento
> **Linguagem:** Java
> **Tipo:** Aplicação CLI (Command Line Interface)
> **Persistência:** Memória durante a execução
> **Frameworks:** Nenhum
> **Banco de dados:** Nenhum
